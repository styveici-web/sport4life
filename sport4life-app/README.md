# Sport4Life

Web app statique de suivi sportif et nutritionnel pour la prise de masse. HTML, CSS et JavaScript, sans étape de build.

- Séance du jour selon le matériel disponible
- Bibliothèque de 19 exercices avec filtre par matériel
- Profils locaux (localStorage), sans compte
- Style Liquid Glass en CSS

Les données restent dans le navigateur. Conseils généraux, pas un avis médical.
Les images d'exercices sont à venir (licence à choisir).
