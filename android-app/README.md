# Sport4Life Android

Emballage Capacitor de l'appli web (dossier `sport4life-app`). Le projet Android est généré à chaque build par le workflow `.github/workflows/android.yml`.
L'APK debug se télécharge dans l'onglet Releases (version `android-latest`) ou dans les artifacts du run.
Les notifications sont locales (plugin `@capacitor/local-notifications`), sans serveur.
